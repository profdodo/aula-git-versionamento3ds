# Desafio 2 - Conventional Commits

Classifique os commits abaixo:

```text
Adiciona recuperação de senha
Corrige erro no login
Atualiza README
Reorganiza autenticação
Adiciona foto de perfil
Corrige validação de e-mail
```

Use os prefixos:

```text
feat
fix
docs
refactor
```

Depois escreva as mensagens completas no formato Conventional Commits.
